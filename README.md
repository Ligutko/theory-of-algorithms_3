# Лабораторна робота №3. Найкоротші шляхи: алгоритми Дейкстри та Флойда

Дисципліна «Математична логіка та теорія алгоритмів», ВНТУ.
Виконав: Лігутко А.А., група СА-24б, варіант 2.

Програмна реалізація двох алгоритмів для зваженого орієнтованого графа
варіанта 2 (6 вершин, 6 дуг). Граф подано матрицею ваг, бо Флойд на кожному
кроці перераховує відстані між усіма парами вершин.

- **Дейкстра** (від вершини `a`): протокол зі стовпцями «Множина U» і D
  на кожному кроці та відновлені шляхи через попередників.
- **Флойд**: усі матриці A0 … A6 і перехресна перевірка рядка `a` фінальної
  матриці з результатом Дейкстри.

## Файли

| Файл | Призначення |
|---|---|
| `lab3_shortest_paths.py` | обидва алгоритми, матриця ваг, виведення |

## Запуск

Потрібен Python 3.8 або новіший, зовнішніх бібліотек немає.

```
python lab3_shortest_paths.py dijkstra   # лише Дейкстра
python lab3_shortest_paths.py floyd      # лише Флойд
python lab3_shortest_paths.py            # усе разом і перехресна перевірка
```
